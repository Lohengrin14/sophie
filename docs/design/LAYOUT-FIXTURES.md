# Тестовая развеска

Сначала подготовлен фронтенд с [пятью размерами](CANVAS-SIZES.md), затем локальная БД наполнена десятью простыми тестовыми холстами. Цвет, номер, перекрестие и рамка помогают сравнивать центрирование и видеть края. PNG нарисованы программно из SVG через Sharp, без генерации ИИ. Пропорции файлов соответствуют указанным сантиметрам.

На [главной](http://127.0.0.1:3000/ru) стоят первые три — маленький, средний и большой. В [каталоге](http://127.0.0.1:3000/ru/works) можно посмотреть весь набор. 08 отмечен как проданный, 09 — в резерве, чтобы проверить фильтры и состояния. Суммы условные. На самих тестовых изображениях есть подписи; обычные подписи и цены на главной по-прежнему скрыты.

## Повторить на чистой локальной установке

```sh
npm run db:up
npm run seed:layout
npm run dev
```

Команда `seed:layout` читает `.env.local` и разрешает только loopback-адрес БД. Набор использует ссылки `layout-study-v1-01` … `layout-study-v1-10`, загружает изображения в обычную медиатеку и публикует оба перевода. Существующие записи с такими ссылками пропускаются. Не создаёт новых сотрудников и не меняет правила цен.

Набор помечен `demo: true`, `featured: true` и порядком −1000 … −991, чтобы его было видно первым. Другие работы и их порядок не изменены. Чтобы закончить эксперимент, можно снять «Показывать на сайте» у тестовых работ в админке. БД и загруженные PNG в Git не попадают; в коммите хранится воспроизводимый скрипт.
