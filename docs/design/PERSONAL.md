# Личный сайт художника

Графит становится темой по умолчанию. Сохранённый выбор посетителя имеет приоритет; остальные четыре палитры доступны для сравнения.

Хедер остаётся компактным: имя набрано курсивной Lora, рядом небольшой графический знак. Навигация без плашек: «картины / на заказ / обо мне / написать». Выбранная страница выделена цветом и точкой; на графите — приглушённым лаймовым. На телефоне меню раскрывается крупными строками. Переключатель языка показывает язык, на который можно перейти.

Тексты от первого лица, без образа команды или студии: «Написать мне», «Что нарисуем?», «Цену и срок уточню…». Описания заказа сокращены, сведения о сроках, доставке и приватности сохранены. Биография и имя из админки не переписываются.

Стили направления: `src/styles/artist-site.css`. Новые декоративные акценты относятся к хедеру; изображения и расположение картин не меняются.
