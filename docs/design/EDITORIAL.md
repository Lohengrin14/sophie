# Типографика и сетка по Pinterest-референсам

Основной ориентир — [последний референс](https://pin.it/4M0RfnV0h): прямой гротеск, мелкая навигация в колонках, изображения разных размеров, спокойное поле между ними. Остальные: [книжный каталог](https://pin.it/3XCTUtAk3), [магазин](https://pin.it/5kkGciPBX), [типографика категорий](https://pin.it/2yM3DT5pg), [портфолио режиссёра](https://pin.it/6Kb1KVyfv).

Это интерпретация общего направления. Точное название шрифта в картинках не установлено. Для сайта выбран Onest: прямой гротеск с кириллицей и латиницей, разными насыщенностями для имени, заголовков и мелких подписей. Файл хранится локально в `public/fonts/onest`, вместе с лицензией OFL; браузер не обращается к Google Fonts. Курсивные Lora и Manrope больше не загружаются публичным сайтом.

В хедере ссылки «картины / на заказ / обо мне» идут в одну строку, имя слева и компактные настройки справа. Активный раздел выделяется только цветом названия, без точки. Стрелки возле «написать» и языка удалены. На телефоне ссылки открываются через кнопку меню единым вертикальным списком. На главной остаются только картины, немного увеличены внешние поля; порядок, размеры и пропорции работ сохраняются.

Текущие палитры — четыре сезона, тёмная зима по умолчанию. Они заменяют прежние десять вариантов. На компьютере варианты показаны в две колонки, на телефоне — в одну с прокруткой. Панель закрывается Escape или нажатием вне её, чтобы можно было сделать скриншот.

В «Обо мне» фотография слева, справа — имя, псевдоним, контакты и общая информация; на телефоне фотография идёт первой. Прямые контакты доступны без заполнения формы на странице заказа. Старый адрес `/contact` переводит к контактам в «Обо мне».

Текущее направление заменяет курсивное оформление из `PERSONAL.md`. Значения всех палитр — в `THEMES.md`.
