# Пять размеров холстов

Галерея использует одинаковые ячейки CSS Grid. В каждой — центрированный контейнер одного из пяти размеров. Реальная ширина и высота в сантиметрах выбирают размер отображения, а пропорции изображения сохраняются через `object-fit: contain`.

| Длинная сторона холста                | Масштаб | Доля максимальной области |
| ------------------------------------- | ------- | ------------------------- |
| До 42 см включительно, в том числе A3 | 1×      | 50%                       |
| До 50 см                              | 1,25×   | 62,5%                     |
| До 60 см                              | 1,5×    | 75%                       |
| До 75 см                              | 1,75×   | 87,5%                     |
| До 90 см и больше                     | 2×      | 100%                      |

60 × 90 и 120 × 120 попадают в последний контейнер. Квадрат остаётся квадратом. Поворот холста не меняет масштаб. Это условные ступени для композиции, а не точная сантиметровая модель стены. Пороговые значения заданы в `src/lib/canvas-size.ts` и не требуют изменений структуры БД.

Главная по-прежнему показывает три работы без цен и подписей. Полный каталог использует те же размеры, с прежними ценами, фильтрами и сведениями. При наведении и фокусе сохраняется небольшое увеличение; уменьшенное движение учитывается. Ряды выравниваются по центру, вокруг маленьких картин намеренно больше воздуха.

Проверки логики: A3, границы диапазонов, поворот, ограничение сверху и некорректные старые размеры. Production build с TypeScript и 16 unit-тестов прошли.
