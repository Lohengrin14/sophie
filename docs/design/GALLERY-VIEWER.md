# Галерея и предпросмотр

Главная остаётся стеной работ без подписей. Размер и последовательность управляются из админки.

## Предпросмотр

У картины один постоянный визуальный контейнер. При наведении меняются только transform и порядок наложения; исходное изображение не скрывается ради заново созданной копии. Адрес обложки одинаков для обычного вида и предпросмотра. Соседние картины не перемещаются. Увеличение ограничено viewport и шапкой.

Открытие задержано на 100 мс, закрытие — на 130 мс. Увеличенный контейнер остаётся частью ссылки: движение по его краю не перескакивает на соседнюю работу. Transform длится 520 мс. Первый ракурс меняется через 1300 мс, остальные — каждые 2600 мс.

`GalleryFrames` хранит уже показанные кадры в DOM. Следующий загружается заранее, а видимый меняется только после загрузки и декодирования изображения. Предыдущий остаётся на месте во время ожидания. Crossfade — 480 мс. Вне предпросмотра используется обложка. Для reduced motion автопоказ и переходы выключены.

На телефоне удержание включает увеличение до отпускания или отмены касания. Нативное меню долгого нажатия отключено для этой области, вертикальный скролл и pinch zoom остаются доступны.

## Карточка и большой просмотр

Стрелки появляются при наведении или фокусе с клавиатуры; на touch-устройствах доступны постоянно. Крайняя недоступная стрелка скрывается. Миниатюры, клавиши ← / → и свайпы переключают один набор изображений.

Основное фото открывает нативный modal dialog с тёмным фоном. Закрытие — кнопкой или Escape; фокус возвращается назад, фон не прокручивается. Есть режим с уменьшенными полями и скрытой лентой миниатюр. Высокое разрешение подгружается поверх уже закешированного изображения. Содержимое большого просмотра монтируется только при открытии.

## Изученные подходы

Без установки зависимостей изучены официальные материалы:

- [Floating UI: hover](https://floating-ui.com/docs/usehover) и [задержки](https://floating-ui.com/docs/floatingdelaygroup) — сохранение области наведения и небольшая задержка закрытия.
- [PhotoSwipe: progressive enhancement и загрузка](https://photoswipe.com/getting-started/), [переходы](https://photoswipe.com/opening-or-closing-transition/) — стабильное изображение во время загрузки и отдельные переходы просмотра.
- [Пример Яндекс Картинок](https://yandex.ru/images/search?text=фото%20гор) — минимальные элементы управления рядом с изображением. Структура просмотрщика осмотрена через доступность браузера; точное визуальное копирование не выполнялось.

Собственная реализация использует React, CSS и существующий next/image; код библиотек не копировался.

## Проверки

Production build / TypeScript, unit-тесты границ viewport и навигации, проверки RU/EN и пользовательских сценариев через локальный сервер. В Safari Responsive Design 390×844 подтверждены переход к работе, выбор ракурса и открытие/управление диалогом через accessibility tree. Полная оценка плавности в активном окне и жестов на физическом телефоне остаётся необходимой: повторный доступ к окну завершился `cgWindowNotFound`, координатный ввод — `noWindowsAvailable`.
