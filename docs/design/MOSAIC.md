# Единая галерея

Главная RU/EN содержит первые 100 опубликованных галерей соответствующего языка, без подписей, описаний и цен под изображениями. Бывший список `/works` перенаправляет на главную; страницы отдельных работ сохраняют URL для ссылок и заявок.

Автоматическая раскладка заполняет свободные прямоугольные участки по порядку. Первый элемент размещается слева сверху. Начало каждой следующей работы располагается после предыдущей при чтении слева направо, сверху вниз: маленькая работа с последним приоритетом не поднимается выше предыдущих ради заполнения пробела. Разные высоты холстов могут оставлять свободные места.

Позиции рассчитываются отдельно для большого экрана, планшета и телефона. Нет случайных чисел: одинаковый набор и параметры дают одинаковую композицию при обновлении. Изображения целиком вписываются в свои области и немного увеличиваются при наведении; уменьшенное движение учитывается.

Размер на доске имеет 10 шагов от 1× до 4×, независимо от реального холста. Для пустого ручного значения используется фиксированный шаг 4. Сортировка: приоритет 1–50 по возрастанию, размер на доске по убыванию, название, ID. Первую галерею определяет этот порядок; идентификатор конкретной работы в код не зашит.

Настройки, обложка и дополнительные изображения описаны в [инструкции мастерской](../ADMIN.md). Пронумерованные надписи внутри тестовых PNG — часть самих изображений; интерфейс не добавляет к ним подписи.

Текущая шкала — 10 шагов от 1× до 4× с фиксированным fallback 4; сантиметры больше не выбирают масштаб. Порядок: приоритет 1–50, масштаб по убыванию, название, ID. Интерактивный просмотр описан в [GALLERY-VIEWER.md](GALLERY-VIEWER.md).
