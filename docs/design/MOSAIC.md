# Единая галерея

Главная RU/EN содержит все опубликованные галереи соответствующего языка, без подписей, описаний и цен под изображениями. Бывший список `/works` перенаправляет на главную; страницы отдельных работ сохраняют URL для ссылок и заявок.

Автоматическая раскладка first-fit заполняет свободные прямоугольные участки. Первый элемент размещается слева сверху. Остальные размещаются по входному приоритету; небольшая работа может визуально попасть в свободное место выше другой, поэтому приоритет задаёт очередность упаковки, а не жёсткий порядок чтения строк.

Позиции рассчитываются отдельно для большого экрана, планшета и телефона. Нет случайных чисел: одинаковый набор и параметры дают одинаковую композицию при обновлении. Изображения целиком вписываются в свои области и немного увеличиваются при наведении; уменьшенное движение учитывается.

Пять категорий размера сохраняются. Художник может выбрать размер на доске 1–5 независимо от реального холста. Если ручной размер ещё не задан, действует автоматическая категория по длинной стороне. Приоритет берётся из админки, меньшее число раньше, равенство разрешается ID. Первую галерею определяет этот порядок, идентификатор конкретной работы в код не зашит.

Настройки, обложка и дополнительные изображения описаны в [инструкции мастерской](../ADMIN.md). Пронумерованные надписи внутри тестовых PNG — часть самих изображений; интерфейс не добавляет к ним подписи.
