# Палитры сайта

Кнопка с палитрой в хедере открывает десять вариантов. Выбор применяется сразу ко всему публичному сайту и сохраняется на год в cookie `artist_theme`. При перезагрузке сервер сразу отдаёт выбранные цвета. Админка использует своё оформление.

| Тема                     | Фон       | Хедер     | Акцент    |
| ------------------------ | --------- | --------- | --------- |
| 1. Монохром              | `#ffffff` | `#f3f3f3` | `#202020` |
| 2. Бумага                | `#f8f5ef` | `#eee9df` | `#6c5b43` |
| 3. Туман                 | `#f5f7f9` | `#e9edf1` | `#455f73` |
| 4. Шалфей                | `#f3f5f0` | `#e7ece1` | `#4d6547` |
| 5. Графит — по умолчанию | `#1b1d1f` | `#141618` | `#ddd8cc` |
| 6. Сливочный             | `#f5f1e3` | `#ede7d4` | `#6c481d` |
| 7. Камень                | `#dcdcd7` | `#d0d1ca` | `#2b5648` |
| 8. Пудра                 | `#eee3e1` | `#e5d5d1` | `#803e50` |
| 9. Олива                 | `#20251e` | `#171d16` | `#d0d9ae` |
| 10. Чернила              | `#1a2130` | `#131a27` | `#c0d1e8` |

Исходные цвета картин не меняются. Полноэкранная галерея сохраняет нейтральный тёмный фон во всех темах.

Для сравнения скриншотов выберите тему и закройте панель клавишей Escape или нажатием вне панели. Стрелки и Home/End переключают варианты с клавиатуры. Названия переведены на русский и английский.

Все значения находятся в `src/lib/site-themes.ts`, оформление переключателя и тематические поправки — в `src/styles/site-themes.css`.
