# Мастерская

Вход: http://127.0.0.1:3000/admin. Учётные данные хранятся в локальном `.env.local`.

В шапке пять разделов: **Художник**, **Сотрудники**, **Галерея**, **Цены и сроки**, **Заявки**. Сотрудник видит только доступные ему разделы. Переключатель Русский / English меняет интерфейс и язык редактируемых переводов. Имя, контакты, изображения и числовые параметры общие; название, описание и биография переводятся отдельно.

## Художник

Имя, псевдоним, ссылки, почта, биография и фотография. Фото публикуется на странице о художнике. Заполненные значения CMS имеют приоритет над резервными env. Каждый блок сохраняется отдельно.

## Галерея

Одна запись — одна работа, до десяти фотографий вместе с обложкой. Обложка выбирается нажатием на изображение. Загрузка фото и выбор обложки подтверждаются кнопкой «Сохранить». Удаление фотографии из галереи не удаляет файл из медиатеки.

- Порядок на главной: целое **1–50**, где 1 — первое место, 50 — последнее. При равенстве приоритета сначала более крупный размер на доске, затем название по алфавиту, затем ID.
- Размер на доске: **10 шагов от 1× до 4×**, независимо от сантиметров. Старые пустые значения получают фиксированный шаг 4.
- Сантиметры задают только пропорции и ориентацию изображения, а также реальные характеристики в заявке.
- Наличие: доступна или продана. Старый резерв переведён в доступные работы.
- Цена вводится обычной суммой, валюта выбирается списком. Смена валюты не конвертирует сумму.
- Публикация требует названия для соответствующего языка. Переименование не меняет адрес.

Столбцы таблицы сортируются нажатием на заголовок. Стрелка и тёмный заголовок показывают текущую сортировку. По умолчанию — приоритет по возрастанию.

## Цены и сроки

Понятные формы предварительных расценок: сюжет, техника, размер, диапазон цены и срок готовности, включение в форму заказа. Эти данные дают предварительную оценку посетителю, окончательные условия обсуждаются лично.

## Заявки

По умолчанию открыты актуальные заявки, сортировка по дате от новых к старым. Завершённые и отменённые — во вкладке «Архив». Для возврата из архива измените статус на активный.

Данные посетителя, сообщение, оценка и приватные референсы собраны в карточке. Редактируется только статус: выберите его, нажмите «Сохранить» и подтвердите изменение. При уходе с несохранёнными изменениями появляется предупреждение. Статус не меняет наличие картины автоматически.

## Сотрудники

Администратор имеет все права. Для сотрудника доступны переключатели «Чтение / Изменение» по каждому разделу. Изменение включает чтение; ограничения проверяются сервером, включая прямые вызовы API. Доступы и роль назначает администратор. Старые владельцы сохраняют прежний полный доступ. Новые сотрудники по умолчанию не имеют доступа к разделам.

## Дополнительные инструменты

Шестерёнка в шапке открывает технические редакторы Payload, медиатеку, API, аккаунт и выход. Приватные референсы защищены тем же доступом, что и заявки.

При обновлении старой локальной базы перед первым запуском новой схемы:

```sh
node_modules/.bin/node --env-file=.env.local scripts/upgrade-studio.mjs
```

Скрипт нормализует старые приоритеты и резерв, задаёт фиксированный размер пустым записям. Аккаунты, файлы, цены и сантиметры не меняет. Production-миграции и резервное копирование готовятся отдельно перед деплоем.
