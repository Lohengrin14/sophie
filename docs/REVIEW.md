# Итоговое ревью

## Проверено и исправлено

- Перевод охватывает пользовательские вкладки и метаданные технических экранов: поля, подсказки и варианты выбора. Исходные данные посетителей и названия картин сохраняются.
- Права проверены через REST API на временных аккаунтах: чтение без записи, недоступность приватных заявок и файлов, запрет повышения роли, создание/изменение/удаление обычного сотрудника с доступом к сотрудникам. Только администратор назначает доступы.
- Диапазоны 1–10 и 1–50 ограничены сервером. Сортировки таблиц проверены через API, для локализованных названий передаётся явный locale.
- Завершённые и отменённые заявки отделяются архивным фильтром. Несохранённый выбор статуса защищён при уходе, сортировке, смене страницы и фильтров.
- Диапазоны цен и сроков проверяются также на сервере при частичном PATCH. Перевод деталей заявки сохраняет исходное название картины.
- Публичная карточка запрашивается по slug напрямую, поэтому ссылка не зависит от лимита первых 100 работ на главной.
- Увеличенное превью не меняет сетку и ограничено viewport. Навигация не выходит за границы изображений, миниатюры не прокручивают всю страницу. Для reduced motion автопоказ выключен.

## Пять замечаний перед публичным запуском

1. **Визуальная приёмка остаётся открытой.** Browser host недоступен, нативное окно возвращает белый снимок без дерева содержимого. Серверные ответы и тесты не заменяют проверку жестов на телефоне, фокуса и реального окна MacBook.
2. **База пока работает через dev schema push.** Перед production нужны версионированные миграции и проверенный сценарий восстановления резервной копии. Скрипт локального обновления не заменяет production-миграцию.
3. **Файлы сохраняются локально.** При размещении нужны постоянный диск или объектное хранилище и отдельное резервирование. Откат транзакции БД сам по себе не гарантирует уборку файлов после неудачной загрузки.
4. **Уведомления не настроены.** Новые заявки сейчас проверяются в админке. Почтовый адаптер для восстановления пароля и доставка уведомлений требуют настройки при деплое.
5. **Лимит заявок привязан к контакту.** Уже есть ограничение размера файлов, проверка изображений, same-origin и лимит обращений по контакту, но сменой контакта такой лимит обходится. Перед публичной ссылкой стоит добавить защиту на уровне инфраструктуры и мониторинг ошибок.

## Пять предложений следующего этапа

1. Собрать реальные фото: обложку, детали и картину в интерьере; проверить подписи изображений RU/EN.
2. Провести короткую приёмку с самим художником: добавить работу, сменить обложку, обработать заявку без помощи разработчика.
3. Добавить перетаскивание работ с сохранением приоритета, если ползунков окажется недостаточно.
4. При росте коллекции добавить порционную загрузку главной: сейчас показываются первые 100 опубликованных работ, прямые ссылки при этом независимы.
5. После выбора палитры согласовать мобильные отступы, скорость смены ракурсов и размер фотографии на реальных устройствах.

Проверки этой итерации: production build / TypeScript, 35 unit-тестов, `test:studio`, `test:access`, `test:smoke`. Тесты удаляют только свои временные записи и файлы. `.env.local` и приватные загрузки не включаются в Git. Развёртывание и публикация не выполнялись.
